In the coming weeks, the Teams SDK documentation hosted on this site will be moved to [Microsoft Learn](https://learn.microsoft.com) and consolidated with the [Teams platform developer documentation](https://learn.microsoft.com/microsoftteams/platform/).

Most of the information from the documentation here is already there, in some cases more fully integrated into the larger platform documentation. The upcoming work will complete the migration and remove the documentation from this site. URLs of the article pages on this site will be redirected to the equivalent documentation pages on Learn.

<!-- truncate -->

## Why are the docs moving?

Learn is the official home for documentation about Microsoft products, including [Teams platform](https://learn.microsoft.com/microsoftteams/platform/), of which Teams SDK is an integral and inseparable part. Consolidating our documentation on Learn will provide a consistent experience for developers exploring and reading the docs about all aspects of the platform and the entire connected Microsoft 365 ecosystem. It also offers benefits like localization and agentic access via the [Learn MCP server](https://learn.microsoft.com/training/support/mcp-get-started) and [Microsoft Docs agent skill](https://microsoft.github.io/skills/#skill=microsoft-docs).

## Where should I look for Teams SDK documentation now?

The [Teams platform developer documentation](https://learn.microsoft.com/microsoftteams/platform/) is becoming the official home of Teams SDK documentation. URLs of article pages from this site will be redirected to the appropriate pages on Learn once the content migration is complete.

On Learn, you can explore all of the Teams platform and SDK documentation through the table of contents, site search, or external search engines, which rank Learn highly as a canonical source of developer information about Microsoft products. For agentic usage, configure the previously mentioned [Learn MCP server](https://learn.microsoft.com/training/support/mcp-get-started) and/or [Docs agent skill](https://microsoft.github.io/skills/#skill=microsoft-docs) in your agent setup, in addition to the [teams-dev agent skill](https://learn.microsoft.com/microsoftteams/platform/coding-agent-skill).
