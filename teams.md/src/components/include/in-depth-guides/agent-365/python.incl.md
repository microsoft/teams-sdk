<!-- availability-note -->

:::warning Preview
Agent 365 support is available starting in Teams SDK `2.1.0a1` for Python. Preview APIs can change before general availability.

```bash
pip install "microsoft-teams-apps==2.1.0a1" "microsoft-teams-api==2.1.0a1"
```

Pin the exact preview version for every `microsoft-teams-*` package your app installs directly. The default PyPI version still resolves to the 2.0.x stable line.
:::
