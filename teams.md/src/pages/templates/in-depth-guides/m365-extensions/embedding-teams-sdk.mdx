# Embedding the Teams SDK

M365 Extensions installs a middleware on an existing [Microsoft 365 Agents SDK](https://github.com/microsoft/Agents) app's adapter that routes matching Teams-channel activities to a Teams SDK app, while everything else — non-Teams channels, and Teams turns with no matching Teams SDK route — continues through the host app unchanged.

## Wire the Teams SDK into your host app

A single call creates the Teams SDK app and installs the routing middleware. It borrows the host app's `clientId`, `tenantId`, and token provider from the Agents SDK's connection manager, so outbound Teams API calls (sending messages, adding reactions, and so on) are authenticated with the same identity as the host app — no separate credential configuration is needed.

<LanguageInclude section="wiring" />

The Teams SDK app returned by this call is a normal app instance: register routes on it with the same APIs you would use in a standalone Teams SDK app (message handlers, dialogs, message reactions, and so on).

## How routing works

For every inbound turn, the middleware:

1. Checks whether the activity arrived on the Teams channel (including Teams sub-channels, e.g. `msteams:COPILOT`). Non-Teams channels always continue straight to the host app.
2. For Teams-channel turns, checks whether a route was registered to bypass Teams routing for this activity (see [Bypass Teams routing](#bypass-teams-routing-for-specific-activities)). If so, the turn continues to the host app.
3. Otherwise, checks whether the Teams SDK app has a route that matches the activity. If it does, the Teams SDK handles the turn and the host app's handler for that turn is skipped. If no route matches, the turn falls through to the host app.

You can run the same Teams-channel check yourself, for example to change host-app behavior based on the channel:

<LanguageInclude section="is-teams-channel" />

| Channel | Teams SDK route matches | Teams SDK route doesn't match |
|---|---|---|
| Teams (`msteams`) | Handled by the Teams SDK | Falls through to the host app |
| Any other channel | N/A — Teams routing never applies | Handled by the host app |
