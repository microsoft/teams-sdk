# Agent 365

[Microsoft Agent 365](https://learn.microsoft.com/microsoft-agent-365/) lets you run an agent as an AI teammate with its own identity in Microsoft 365. Teams SDK handles the Activity Protocol and identity-aware messaging that your agent needs in Teams.

<LanguageInclude section="availability-note" />

With Teams SDK, your app can:

- Receive messages addressed to an Agentic User.
- Reply with the correct Agentic User identity.
- Send proactive messages with an explicit agent identity.
- Handle Agentic User lifecycle events.
- Add Agent 365 identity and correlation context to telemetry.

These guides focus on Teams SDK. For broader platform concepts and administration, use the [Agent 365 documentation](https://learn.microsoft.com/microsoft-agent-365/).
